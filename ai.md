# AI Usage

## AI Tools Used During Development

### ChatGPT

ChatGPT was used as a development-support and documentation assistant during the project.

It was used for:

- Understanding and structuring the routing problem
- Organizing Mysuru jurisdiction data
- Designing the database structure
- Developing SQL tables and routing rules
- Documentation assistance
- Debugging and development guidance
- Preparing project presentation content
- Reviewing project workflow and repository organization

## AI Inside the Product

No separate AI/ML model is currently used as the core routing engine.

The routing mechanism is based on:

- Location
- Geographical boundary data
- Jurisdiction information
- Issue categories
- Authority and department mappings
- Predefined routing rules

Therefore, the current routing system is rules-based rather than an AI/ML prediction model.

## Human Verification

Project data and implementation decisions were reviewed by the team before being included in the project repository.
